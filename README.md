# Sellpert 2.0 — منصة عمليات وتحليلات المبيعات

واجهة عربية متعددة المتاجر لإدارة الطلبات والمنتجات والمخزون والإعلانات
والاستيراد من المنصات، مع لوحة إدارة للمنصة ونماذج عامة لطلبات الخدمة.

التقنيات: React 18 + TypeScript + Vite، وSupabase للمصادقة وقاعدة البيانات
والتخزين وEdge Functions. الواجهة في الكود مقيدة بمسارات المرحلة الأولى؛
وجود صفحة في الكود لا يعني أنها متاحة من التنقل.

هذا وصف لتنفيذ المستودع، وليس تحققًا من Production. تفعيل التكاملات وتطبيق
الترحيلات وإعدادات الاستضافة وقاعدة البيانات الحية: `NEEDS_CONFIRMATION`.
وجود كود أو ملف migration أو إعداد محلي لا يثبت الحالة الإنتاجية.

## الإعداد المحلي

استخدم npm وNode 22.12 أو أحدث ضمن سلسلة Node 22 المستخدمة في CI.
يعلن المشروع `>=22`، لكن اعتماديات البناء تتطلب حدًا أدنى أعلى ضمن هذه السلسلة.

```sh
npm ci
```

ملف البيئة المحلي الموثق هو `.env` في جذر المشروع؛ وجوده غير مضمون في
نسخة جديدة من المستودع. يدعم إعداد Vite الافتراضي أيضًا `.env.local`.
المتغيرات المطلوبة، دون قيم:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

لا تضع مفاتيح الخدمة أو أسرار التكاملات في متغيرات المتصفح، ولا ترفع ملفات البيئة.
تأكد من أن البيئة الخلفية مقصودة ومعزولة قبل أي تجربة تكتب بيانات.

## الفحوص والتشغيل

```sh
npm run build
npm run lint
npm test
```

للتطوير المحلي عند الحاجة: `npm run dev`.
اختبارات المتصفح وSQL وDeno مستقلة عن `npm test`؛ راجع مصفوفة الفحوص في دليل التطوير.

## قاعدة البيانات والتوثيق التاريخي

مصدر إعادة بناء المخطط هو `supabase/migrations/` كاملًا وبالترتيب.
`supabase-schema.sql` قديم ولا يصلح لتهيئة المشروع الحالي.
`src/lib/database.types.ts` لقطة مولدة قديمة، ولا تثبت تطابق المخطط الحي.
تقارير يونيو/يوليو تحت `docs/` تاريخية، ويجب التحقق من ادعاءاتها في الكود الحالي.

لا تنفّذ deploy أو تطبّق أي migration، حتى محليًا، أو تعدّل Production دون
طلب صريح يحدد الإجراء والبيئة. التغييرات المدمرة تتطلب موافقة على التغيير المحدد.
